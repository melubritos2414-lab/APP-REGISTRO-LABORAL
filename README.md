Aplicación de Registro Laboral
Aplicación web desarrollada para registrar días laborales, actividades y horas trabajadas.
Es un proyecto real, utilizado actualmente por un usuario para organizar su actividad laboral diaria.

✨ Características principales
Registro de días trabajados

Registro de actividades

Cálculo de horas

Historial de registros

Interfaz simple y fácil de usar

Funciona sin conexión (PWA)

Instalación como app en el móvil o PC

Datos guardados localmente en el dispositivo del usuario

🧩 Tecnologías utilizadas
HTML5 / CSS3 / JavaScript

Service Worker (modo offline)

Web Manifest (instalable como app)

LocalStorage / IndexedDB

Git/GitHub para control de versiones

📱 Funcionalidad PWA
La aplicación incluye:

service-worker.js → permite funcionamiento offline

manifiesto.webmanifiesto → permite instalar la app

favicon.png → icono de la aplicación

Esto permite que el usuario la use como una app normal en su móvil o PC.

🔧 Instalación
Clonar el repositorio

Abrir índice.html en el navegador

Instalar la app desde el navegador (opción “Instalar aplicación”)

Los datos se guardan automáticamente en el dispositivo del usuario
